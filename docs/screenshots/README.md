# Store screenshots

Generated by `npm run shots`. The subject is Wikipedia's article on marginalia —
the practice the extension is named after — so the listing shows the tool doing
the thing it describes. Notes are planted on real sentences, and the article's
own sidebars are collapsed first, on the live page: a capture is taken with the
page's scripts blocked, so its controls are inert afterwards.

| File | Shows |
|---|---|
| `1-notes-in-margin.png` | Notes beside the lines they belong to, leader line on the active one |
| `2-first-save-panel.png` | The first-save panel, with "save here next time too" on by default |
| `3-notes-hidden.png` | Notes hidden: the captured page is untouched underneath |
| `4-reopened-from-disk.png` | The saved file opened from disk, notes intact, no extension involved |

Upload in that order — the first is the listing's thumbnail.

`sample-saved-page.html` is the file shot 4 was taken from. Opening it in any
Chromium browser shows what a saved page is: one file carrying the page, the
notes, and the code to read them.

Regenerate after any change to the note layer, so the listing never shows a
version that no longer exists.
